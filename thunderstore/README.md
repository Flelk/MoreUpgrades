# MoreUpgrades

The shop between levels stocks **more upgrades**, and favors the ones you want.

- **+33% upgrade slots**: 4 upgrades per shop instead of 3 (configurable, up to +300%).
- **Favored upgrades**: Grab Strength, Health and Energy (stamina) are 3x as likely to be picked as any other upgrade.
- Vanilla rules still apply: each upgrade's per-shop limit, the price going up 50% per purchase, and unaffordable upgrades being skipped most of the time.

## Who needs it
**Only the host** (or you, solo). The host rolls the shop, and everyone sees what it rolled. A guest with the mod gets no effect.

## Config (`gabe.moreupgrades.cfg`, or r2modman's Config editor)
| Setting | Default | |
| --- | --- | --- |
| ExtraUpgradesPercent | 33 | 33 = 4 upgrades, 100 = 6 |
| FavoredUpgrades | `Grab Strength, Health, Energy` | comma-separated; empty = no bias |
| FavoredWeight | 3 | 1 = vanilla odds |
